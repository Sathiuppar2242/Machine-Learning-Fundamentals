# Iris Dataset Analysis

## Dataset Overview

The Iris dataset is a well-known beginner-friendly dataset used for classification problems in Machine Learning.

It contains measurements of 150 Iris flowers belonging to three different species.

## Number of Samples

The dataset contains:

- 150 total samples
- 120 training samples
- 30 testing samples

## Features

The dataset contains four numerical input features:

1. Sepal Length
2. Sepal Width
3. Petal Length
4. Petal Width

All measurements are represented in centimeters.

## Target Classes

The target variable contains three Iris species:

- Setosa
- Versicolor
- Virginica

Each class contains 50 samples.

## Missing Values

The dataset was checked for missing values.

All six columns contain 150 non-null values, meaning the dataset does not contain missing values.

## Class Distribution

The class distribution is balanced:

| Species | Number of Samples |
|---|---:|
| Setosa | 50 |
| Versicolor | 50 |
| Virginica | 50 |

A balanced dataset is useful for classification because each class is represented equally.

## Statistical Analysis

Descriptive statistics were generated using Pandas.

The analysis included:

- Count
- Mean
- Standard deviation
- Minimum
- 25th percentile
- Median
- 75th percentile
- Maximum

## Conclusion

The Iris dataset is clean, balanced, and suitable for demonstrating a beginner-level supervised Machine Learning classification workflow.
